# Dados

- `raw/`: snapshots originais da API SIDRA, tratados como imutáveis para auditoria. Não versionar extrações grandes.
- `processed/`: tabelas em formato longo normalizadas e pequenos pilotos exploratórios.
- `../reports/outputs/`: indicadores derivados dos scripts.
- `../reports/figures/`: gráficos gerados a partir dos dados disponíveis.

Os dados secundários de piloto estão identificados como tais. Dados sintéticos usados nos testes validam o comportamento do código e não representam os municípios.
