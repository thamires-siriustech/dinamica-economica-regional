# Análise preliminar — produção de soja e milho (2015–2025)

**Status:** exploratório; baseado em transcrição secundária de páginas municipais que declaram IBGE/PAM (SIDRA, tabela 1612) como fonte original. Os dados precisam ser reconciliados com a API SIDRA antes de publicação como base oficial.

## O que está incluído

- 66 registros: 3 municípios × 2 culturas × 11 anos.
- Medidas: produção (t), área plantada (ha), produtividade (kg/ha) e valor da produção (R$ mil nominais).
- Valores monetários nominais; não interpretar a variação de 2015–2025 como crescimento real sem deflator.

## Leitura analítica inicial

1. Sorriso apresenta os maiores volumes absolutos entre os três municípios nas duas culturas em 2025 nesta base compilada.
2. Nova Mutum registra a maior variação percentual do milho neste período, partindo de uma base inicial menor; isso não implica maior produção total.
3. Mudanças na produção podem decorrer de variações de área e/ou rendimento. Decompor essas dimensões antes de atribuir causas.
4. Valor da produção em reais precisa de ajuste pela inflação para comparação real de longo prazo.
5. A base ainda é secundária e deve ser reconciliada linha a linha com a consulta direta ao SIDRA.
